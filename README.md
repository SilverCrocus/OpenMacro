# OpenMacro

An open-source nutrition and macro tracking app, inspired by adaptive-TDEE coaching apps such as MacroFactor.

## Status

Early research and planning. Feature specifications are being written from observed app behavior.

## Clean-room policy

OpenMacro is an independent project and is not affiliated with, endorsed by, or connected to MacroFactor or Stronger By Science.

- No proprietary source code, decompiled code, binaries, or assets (icons, images, copy, fonts) from other apps are committed to this repository.
- Specs in `docs/` describe *behavior* in our own words; the implementation is written from those specs.
- Reverse-engineering artifacts stay local in `research/private/`, which is git-ignored.
